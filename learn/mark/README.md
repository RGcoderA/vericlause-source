# Learn mark

These files are the saved mark VeriClause uses when it reads an NDA, a vendor agreement, terms of service, a privacy policy, or another contract.

The examples are demonstration text, not documents to sign. The terms, privacy policy, and disclaimer in `reference/` are drafts with blanks still in them. They are not published as the live legal pages.

`07-risky-vendor.md` stops before the answer key, so a review of that file cannot read the score sheet.

The checks themselves live in `src/lib/learn/mark.ts`.
